AI coding agents are rapidly joining modern developer toolchains. ProofRun introduces a way to generate local verification receipts to track and confirm the actions of these automated coding tools.

By running verification locally, developers maintain full control over their code environment while ensuring agent outputs are properly validated.

Check out the repo on [GitHub](https://github.com/yebiguo/ProofRun).
