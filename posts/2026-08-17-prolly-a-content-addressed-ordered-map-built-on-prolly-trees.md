Data structure enthusiasts have a new project to check out. Prolly brings a fresh implementation of a content-addressed ordered map built on top of prolly trees.

By utilizing prolly tree design, the project provides an efficient approach to handling verifiable, ordered key-value mappings.

Core highlights of the project include:
- Implemented using prolly tree concepts
- Designed as a content-addressed ordered map
- Openly accessible code repository

Explore the project source code on [GitHub](https://github.com/crabbuild/prolly).
