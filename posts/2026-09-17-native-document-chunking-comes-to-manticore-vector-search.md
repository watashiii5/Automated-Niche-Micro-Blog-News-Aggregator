Handling vector search on long documents just got a lot simpler with Manticore Search. The database engine now supports automatic chunking natively to improve retrieval quality.

Instead of requiring pre-processing pipelines to break up large files before indexing, the platform manages text segmentation internally. This native approach streamlines data ingestion and yields better search results for long-form content.

Key features of this update:
- In-database automatic text chunking
- Optimized vector search for long documents
- Simpler indexing workflows
